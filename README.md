# XXMI 토글 & 메쉬 매니저 플러그인 (Migoto Studio)

3DMigoto 및 XXMI 기반 게임 모드 제작 시, 토글 키 설정(`[Key...]`)과 메쉬 부위별 조건문(`if ... handling = skip ... endif`)을 GUI로 완성할 수 있도록 돕는 Migoto Studio 공식 플러그인입니다.

---

## 주요 기능

### 1. 토글 키 및 변수 설정 (`Keys Tab`)
- **INI 자동 파싱**: 문서 내의 `[Key...]` 섹션과 `[Constants]` 변수 자동 감지
- **단축키 도우미**: 에디터 내장 키 감지 및 3DMigoto 규격 가상키 설정
- **순환 상태 개수 제어**: 1 이상의 자연수를 입력하여 순환 시퀀스(`0, 1`, `0, 1, 2` 등) 자동 구성
- **스마트 upsert**: 기존 주석이나 문서 배치를 보존하며 해당 섹션만 제자리 갱신

### 2. 메쉬 조건문 설정 (`Mesh Tab`)
INI 문서의 메쉬 섹션(`[TextureOverride...]`, `[Component...]`)을 감지하여 변수값에 따른 렌더링 동작을 설정합니다.

- **단순 모드 (1:1 매칭)**:
  - 메쉬 부위 하나당 변수 토글값 하나로 1:1 매칭
  - 특정 값에서 메쉬 숨김(`handling = skip`) 또는 특정 값에서만 표시 설정
- **고급 모드 (복합 조건)**:
  - 다중 변수 & 복합 논리 조건식 (`$dress == 1 && $cloak == 0`)
  - `if`, `else if`, `else`, `endif` 다중 분기 시각적 구성

---

## 사용 방법

1. Migoto Studio에서 모드 폴더를 열거나 INI 파일을 엽니다.
2. 상단 메뉴바 **[플러그인] -> [XXMI 토글 & 메쉬 매니저 열기…]**를 클릭합니다.
3. 상단 툴바에서 대상 INI 파일을 선택하고, 각 탭에서 설정을 편집한 후 **[INI 전체 적용]** 또는 개별 섹션 저장을 클릭합니다.
